# Gravrallye

Höhlenflug-Zeitfahren im Browser: Drehen und Schub gegen die Schwerkraft, drei Etappen mit Boost-Feldern, Sektorzeiten, Medaillen und Geist der eigenen Bestzeit. Inspiriert von *Gravitation* (Net Yaroze, 1998) und *Wipeout*.

**Spielen:** einfach `index.html` im Browser öffnen oder über GitHub Pages.

## Steuerung
| Aktion | Tastatur | Gamepad |
|---|---|---|
| Drehen | ← → | Stick / Steuerkreuz |
| Schub | ↑ | A / RT |
| Luftbremse | ↓ | B / LT |
| Neustart | R | Y |
| Pause | Esc | Start |
| Ton an/aus | M | – |

Auf dem Handy erscheinen Touch-Tasten. Bestzeiten und Geister werden lokal im Browser gespeichert.

Eine einzelne HTML-Datei, kein Build-Schritt, keine Abhängigkeiten außer Google Fonts.
